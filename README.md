# Football Analytics & Prediction Platform

A football analytics platform developed in C. The project aims to bring together football match information, team performance statistics, league standings, historical data analysis, and machine-learning-based match outcome predictions.

## Vision

Build a modular football platform that allows users to explore competitions, follow matches, analyze team performance, and discover data-driven predictions.

## Core Features

- Football match data integration through external APIs.
- Match browsing, fixtures, and results.
- Team statistics and performance analysis.
- League standings and competition management.
- Local CSV data storage and offline access.
- Historical match data processing.
- Three-class match outcome prediction: Home Win, Draw, Away Win.

## Technology Stack

- **Language:** C11
- **Build system:** CMake
- **Libraries:** libcurl, cJSON
- **Data storage:** CSV
- **Machine Learning:** Multiclass Logistic Regression (planned)

## Development Status

The initial foundation is implemented, including API integration, match parsing, validation, CSV storage, standings, team browsing, and automated tests. Historical data analysis and the prediction engine are planned development stages.
